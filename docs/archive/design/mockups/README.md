**ההחלטה:** אייל בחר בכיוון א' (נייר), כמו שהוא, בלי שילובים. השפה שנגזרה ממנו כתובה ב-[`../design-language.md`](../design-language.md) וב-`web/src/index.css`.

`index.html` מציג את שלושתן זו לצד זו (`all.png` הוא צילום שלו), ו-`?only=a` מציג מסגרת אחת. הפונטים בקובץ הזה נטענים מ-Google רק לצורך ההדמיה; במוצר הפונט מאוחסן אצלנו. האייקונים בהדמיה מצוירים ביד; במוצר הם מ-`lucide-react`.

ההדמיה מראה כיוון, לא מפרט של מסך: המבנה הסופי של "היום" נקבע ב-S27.
